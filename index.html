Scrbbl AI

Write a question.
Get a written answer back from AI.

Write anything on your iPad with an Apple Pencil, underline it three times, and the answer appears handwritten below.

Try the free beta on TestFlight, or get the code on GitHub. You'll need your own OpenAI API key.

How it works

  1. Write it down. Any question or text, anywhere on the page.
  2. Underline it three times for a quick AI answer. Pulled from the web if necessary.
  3. Or circle it for a fuller answer with examples.
